# 사주 아케이드 릴스·스레드 발행 저장소

깃허브 액션이 도는 **코드만** 있는 저장소. 영상은 Cloudflare R2(공개 버킷 `saju-shorts/`)에, **예약표·기록은 R2 창고 `shorts/`** 에 있다 (2026-09-25. 전엔 여기 커밋했는데 PC 와 액션이 충돌하고 기록이 계속 자라 저장소가 찼다).

- `작업/쇼츠창고.py` — 예약표·기록 창고. `python 작업/쇼츠창고.py --예약표` 로 본다. 발행·등록은 창고 잠금을 잡고 한다.
- `작업/쇼츠발행.py` — 액션이 30분마다(+워커 10분) 돌리는 발행. 시간 지난 "대기" 건을 유튜브·인스타·스레드·페북에 올린다.
- `작업/스레드하루치.py` — 매일 06:30 스레드 글 3~5개를 만들어 예약표에 넣는다.
- `작업/토큰갱신.py` — 매주 60일 토큰 연장. 깃에 남는 건 금고 `토큰.enc` 하나.
- `작업/스레드자동답글.py`·`답글창고.py` — 스레드 답글 봇 (기록은 R2 `threads-reply/`).

토큰은 저장소에 없다. Secrets: `IG_USER_ID`, `IG_ACCESS_TOKEN`, R2 넷, 텔레그램 둘, `CLAUDE_CODE_OAUTH_TOKEN`.
자세한 건 PC 의 스킬 `사주쇼츠업로드자동화`.
